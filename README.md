**Анти-чит система для обнаружения запрещённого ПО в игре Rust**

---

## 📋 О программе

**Rust Shield Scanner** — это профессиональный инструмент для обнаружения читов и запрещённого программного обеспечения, используемого в игре Rust. Программа сканирует систему и выявляет подозрительные процессы, файлы и записи реестра.

---

## 🎯 Функции

- 🔍 **3 режима сканирования** (Быстрая, Полная, Глубокая)
- 📋 **Консоль логов** с автоскроллом
- 💾 **Сохранение отчётов** в JSON/TXT
- 📞 **Страница "О программе"** с контактами
- 🖥️ **Мониторинг CPU/RAM** в реальном времени
- 🎨 **Современный тёмный дизайн**

---

## 🚀 Установка

### 1. Скачайте релиз
Перейдите в раздел [Releases](https://github.com/SkyWalker-code-creator/RustShieldWorking/releases) и скачайте последнюю версию.

### 2. Запустите программу
Запустите `RustShieldWorking.exe` **от имени администратора**.

### 3. Начните сканирование
Нажмите одну из кнопок: **БЫСТРАЯ**, **ПОЛНАЯ** или **ГЛУБОКАЯ**.
